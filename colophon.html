How this site is built, checked and dated.

How it's built

Static HTML, CSS and JavaScript, served by GitHub Pages with no build step. Type is Pixelify Sans for the wordmark and section titles, Lato for text and Inconsolata for dates and code. The isometric field on the homepage is drawn as SVG and pixel sprites by scripts/build-portfolio-field-art.py.

How it's checked

The scripts in scripts/ check the site:

  • check-polish.mjs pins the layout decisions: no tracked capitals, no middle-dot meta lines, the field in the hero, a fixed evidence label on every project.
  • check-evidence.mjs compares the dates in the lab log, on the project cards and in the report receipts with git.
  • check-portfolio-field.mjs drives the field at five widths, in both themes, with the keyboard and with scripts off.
  • smoke-responsive.mjs loads the pages listed in the script from 320 to 1440 pixels wide and fails on overflow, clipped hero content or a missing image.

The Hallmark design linter was run against the homepage for the 2026 redesign; its before and after results are in _audit/ in the repository.

How dates work

Every date in the lab log and on each report is the day that page was added to this site, taken from git. It is not the day the work was done. Each report links to the commit that added it and to its full history in the public repository.

What stays private

Five of the eight reports end with this note: "Sanitized report prepared for portfolio publication. Raw academic materials and private data are not published." The project cards state what each public summary leaves out.
