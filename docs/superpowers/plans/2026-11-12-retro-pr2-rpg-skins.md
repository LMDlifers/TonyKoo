# Retro PR 2: RPG Skins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship spec section 4. Existing content gets the 16-bit RPG skin: projects become item cards, the filters become a game menu, the lab log becomes a quest log, the field card becomes a dialogue box with a portrait, and buttons press like console buttons. No new copy.

**Architecture:**
- **Pixel frame:** the art builder generates one 24×24 SVG 9-slice pixel frame in day and night variants. A `.pixelFrame` class applies it through `border-image`, and the class is added to existing elements.
- **Cursor, quest mark, press:** the menu cursor is CSS-only. The quest mark is one small generated SVG. The console press replaces the 0.97 scale in `css/craft.css`.
- **Portrait:** one line in `js/portfolio-field.mjs` copies the selected character's still sprite into the dialogue box.

**Tech Stack:** Python standard library (`scripts/build-portfolio-field-art.py`), CSS `border-image`, ES modules, and Node 22 with Playwright checks.

**Spec:** `docs/superpowers/specs/2026-11-11-retro-vellum-design.md`, section 4, Testing for PR 2, and the Amendments.

## Global Constraints

- **Branch:** `feat/retro-pr2`, cut from `main` once the pixel-snap PR has merged. Merge by PR.
- **Content:** no new claims or copy, and the word budget stays at 1744 or under. The dialogue name tag reuses `.personaRole` text. The quest mark is decorative (`aria-hidden="true"`).
- **Art:** generated by the builder only, crisp-edged, using colours from the field palette.
- **No:** emoji, Press Start 2P, or purple/indigo. Every colour is a token, apart from the frame SVGs, which carry palette hex values just as the field SVGs do.
- **Hooks:** keep every existing `data-*`, id, class and test hook. `.filterItem`, `#filter .btn`, `.logEntry` and `.fieldSelectionCard` stay. `pixelFrame` is added alongside them, never in place of them.
- **Press:** rest has a 2px hard shadow with 0 blur. Pressed is `translateY(2px)` with no shadow. Hover is a colour step with `transform: none`. Reduced motion is instant: the global `style.css` rule already handles this.

## Review Focus

1. **Keyboard focus inside framed cards and menu.** `border-image` must not hide `:focus-visible` rings. Task 2 checks the outline on a focused chip.
2. **The ► cursor must not shift the menu layout when the active filter changes.** Task 3 asserts that every chip keeps the same width when it becomes active.
3. **Selecting a hidden-cast character.** Ideas and Methods characters must also get a portrait in the dialogue box. Task 4 selects the Researcher in the Ideas cast.
4. **Press and the old `scale(0.97)` checks.** The PR 1 craft checks assert a scale between 0.96 and 0.98. Task 5 replaces that assertion; nothing else may still expect scale.
5. **Night frames.** Every framed element switches to the night frame in dark mode. Task 1 asserts `border-image-source` changes when `dark-mode` is set.
