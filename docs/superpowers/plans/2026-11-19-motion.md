# Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the motion inventory in the spec: three signature moves, one staged entrance per page, and quiet hover and press responses, with almost no JavaScript.

**Architecture:** One new stylesheet, `css/motion.css`, linked last on every page, holds every motion rule. One new script, `js/motion.js` (about 8 lines), sets a class during navigation. Markup changes are limited to the wordmark letters, the stylesheet and script tags, and view-transition names on four cards and four report titles. One new Playwright check, `scripts/check-motion.mjs`, owns every assertion.

**Tech Stack:** HTML, CSS (scroll-driven animations, cross-document view transitions, `@starting-style`, `linear()`), Node 22 with Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-motion-design.md`. Snippets tested in Chrome 157 are in `docs/research/2026-11-19-css-motion-support.md`; use them as the starting point.

## Global Constraints

- **Branch:** `feat/motion` from `main`. Merge by PR.
- Every moving rule sits inside `@media (prefers-reduced-motion: no-preference)`. Hover movement also sits inside `@media (hover: hover)`.
- Durations: press 100ms, hover 160ms, toggles and small enters 240ms, staged entrance 500ms with 80ms steps. No interaction transition over 300ms.
- Animate `opacity`, `translate`, `scale`, `rotate`, `clip-path`, `filter` and colour only. Exceptions: wordmark letter width and `<details>` height.
- Use `translate` / `scale` / `rotate`, not `transform`, so existing press states in `css/craft.css` keep working.
- No `transition: all`. No new infinite animation on an idle page.
- Text content is unchanged. The wordmark letters stay in the accessibility tree.
- Every existing suite stays green. Most existing checks run with reduced motion and must see no difference.

## Review Focus

1. **Reduced motion.** The repo's global reset does not stop scroll-driven animations or view transitions. Task 1 asserts that with reduced motion nothing runs except the reading-progress bar.
2. **Back and forward cache.** A page restored from cache must not show the navigation bar or replay its entrance. Task 2 asserts the class is cleared on `pageshow`.
3. **The homepage nav brand is a text node next to an image.** The wordmark rewrite must keep the avatar, the link and its `aria-label`. Task 3 asserts the accessible name and the text content.
4. **View-transition names must be unique per page.** A duplicate cancels the whole transition. Task 5 asserts uniqueness on the homepage and each report.
5. **The entrance must not hide content when CSS animation is unsupported or JS is off.** Entrances use `animation … backwards` from keyframes, never a hidden base state. Task 4 asserts content is visible with JS off and with reduced motion.
