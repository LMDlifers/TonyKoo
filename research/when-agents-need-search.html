When agents need search

Choose the smallest control loop that improves validated outcomes, and be explicit about what branches.

TK
Tony Koo13 October 2026 · 4 min read

Research synthesis, not a benchmark claim

Start with a direct path

A fixed workflow is a sensible default when the steps are known. An agent is useful when the system must choose its next step from observations and tools. Anthropic's agent design guide separates workflows with predetermined paths from agents that dynamically control tool use. This distinction is more useful than counting agents.

Start with one agent, a narrow tool set and a testable completion condition. Add routing when tasks require clearly different paths, parallel work when independent tasks can be reconciled, and manager-worker delegation when the manager can verify each handoff. Every added actor creates ownership, cost and failure questions.

Decision rule

Use more search only when branches can be assessed and the measured gain is worth the extra calls, latency and coordination.

Know what the tree contains

Best-of-N compares completed answers. Tree of Thoughts explores intermediate thoughts and can backtrack. Monte Carlo Tree Search (MCTS) builds an action tree: select, expand, simulate or estimate a return, then propagate the result. UCT balances branches with promising observed returns against those with little exploration.

SYMPHONY uses heterogeneous language-model agents to propose and assess branches within an MCTS-style search. Its HotpotQA, WebShop and MBPP comparisons depend on the paper's selected model pools, feedback and budgets. SIFT changes the search object: it explores revised coding-agent harnesses, using pairwise judge rankings to choose candidates while task runs provide the real outcome evidence.

Worked example

A coding agent has three possible fixes for a failing parser. First run a direct baseline and the relevant test. If each partial patch can be compiled and tested, bounded branching may help. If only the final user experience is observable, several independent complete attempts may be simpler than maintaining an action tree.

Give search a budget and a stop rule

Search scores depend on the evaluator. A rollout backed by a real test differs from one backed only by another model's opinion. Define the maximum attempts, token spend, time and escalation point before the loop starts. Record the selected branch and why it passed an independent final check.

Limit

The cited studies report results under particular tasks and model settings. More agents, a deeper tree or a higher judge score do not automatically improve a new workflow.
